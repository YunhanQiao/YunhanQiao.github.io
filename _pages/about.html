About Me

Hi! I am a Ph.D. candidate in Computer Science at Oregon State University, advised by Dr. Christopher Hundhausen in the Software Engineering Education Assessment and Analytics Lab (SEAL). I also work with Dr. Anita Sarma on an EEG research project. GenAI assistants and coding agents can now write and change code for us, but someone still has to understand it. My research sits where two questions meet: Human–AI Programming and Code Comprehension.

I study what developers and students do when they work with tools like GitHub Copilot on unfamiliar, existing codebases (so-called brownfield tasks), and whether faster, more correct work also means deeper understanding. I combine controlled experiments, screen-recorded behavioral analysis, prompt coding, and interviews, and I use what I find to shape how computing education teaches and assesses GenAI-assisted software development. My work appears in ACM TOCE, ICER, and IEEE AIxSE.

Before Oregon State, I earned my M.S. in Software Engineering from Arizona State University, working with Dr. Robert LiKamWa.

Research Interests

Related Keywords: Human–AI Programming, Coding Agents, Program Comprehension, Computing Education, Software Engineering Education, Brownfield Development, Empirical Software Engineering, Mixed Methods

GenAI is changing how software gets built and what programmers need to know. My work is organized around three connected questions:

  1. Perform vs. Understand: When GitHub Copilot makes programmers faster and more correct in unfamiliar code, does their understanding of that code keep up, and which behaviors separate those who understand from those who don't?
  2. Say, Do, Understand: How do developers communicate with coding agents: what they write, what they do while the agent works, and what they can explain afterwards?
  3. Teach & Assess: How should computing education teach GenAI-assisted development so that students verify and explain AI-generated code, and how should we assess correctness and comprehension separately?

Beyond the Prompt: Linking What Developers Ask, Do, and Understand with Coding Agents
Yunhan Qiao, Summit Haque, Christopher Hundhausen
SANER 2027: IEEE International Conference on Software Analysis, Evolution and Reengineering Under Review

We present Say, Do, Understand, an end-to-end workflow for analyzing what developers write to a coding agent, what they do while it works, and what they can explain afterwards. It has five stages (Capture, Prepare, Analyze, Integrate, Interpret) and three instruments: a prompt codebook, a coding scheme for screen-recorded activity, and rubrics for explaining the process and the solution. Applied to ten experienced developers using GitHub Copilot on an unfamiliar codebase, it produced four personas; for two developers, task performance and understanding split apart.

Faster but Not Wiser: GitHub Copilot Decouples Programming Performance from Code Comprehension in Brownfield Tasks
Yunhan Qiao, Md Istiak Hossain Shihab, Summit Haque, Christopher Hundhausen
ACM Transactions on Computing Education (TOCE) Under Review

In a within-subjects study, 15 CS graduate students implemented features in an unfamiliar codebase with and without Copilot. Copilot significantly improved performance, but overall comprehension did not improve (p = 0.59), and performance gains were not associated with comprehension gains. Higher-comprehension participants engaged in verification loops, performing write-then-view transitions 4.7× more often (p = 0.001). We argue for assessing correctness and comprehension separately and teaching students to inspect and explain AI-generated code.

A Systematic Literature Review of the Use of GenAI Assistants for Code Comprehension: Implications for Computing Education Research and Practice
Yunhan Qiao, Md Istiak Hossain Shihab, Christopher Hundhausen
ACM Transactions on Computing Education (TOCE), 26(2), Article 24, 2026 Published

We review 31 studies (2022–2024) that use GenAI to support code comprehension. We classify the approaches and tools, the methods used to study them, and the evidence for their effectiveness. GenAI assistants often give inaccurate or unclear explanations, and novices struggle to write effective prompts. We discuss implications for computing education research and practice and outline directions for future work.

The Effects of GitHub Copilot on Computing Students' Programming Effectiveness, Efficiency, and Processes in Brownfield Coding Tasks
Md Istiak Hossain Shihab, Christopher Hundhausen, Ahsun Tariq, Summit Haque, Yunhan Qiao, Brian Wise Mulanda
ICER 2025: ACM Conference on International Computing Education Research Published

In a controlled experiment, 10 undergraduates added features to a legacy web application with and without Copilot. With Copilot, they finished 34.9% faster and made 50.0% more solution progress, while spending less time writing code by hand and searching the web. In interviews, students worried about not understanding how or why Copilot's suggestions worked, which points to a need for pedagogy that encourages reflection on GenAI suggestions.
